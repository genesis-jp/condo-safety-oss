# 🏢 マンション・集合住宅用 災害時安否確認システム (Open Source Edition)

**[🌐 English README (英語版はこちら)](./README.en.md)**

地震・台風・停電などの災害時や防災訓練において、マンション・集合住宅（管理組合 / 自治会）の**全戸の安否・被害状況・要救助ニーズをリアルタイムで集約するサーバーレスWebアプリケーション**です。

Googleが提供する無料枠の **Google Apps Script (GAS)** と **Google スプレッドシート / Google ドライブ** のみで動作するため、**月額サーバー費用 0円** で導入・運用できます。

## ✨ 主な特徴

1. **サーバー費用・ランニングコスト完全無料（0円）**
   - マンション管理組合のGoogleアカウント（`@gmail.com`）1つだけで、Google Apps Script・スプレッドシート・Googleドライブ上にすべて自動構築されます。
2. **住民の氏名・連絡先を保持しない、情報漏洩に強い設計**
   - 住民のログインは部屋番号と簡易PINだけです。住民の氏名・電話番号・メールアドレスはシステムに保持しません。発災時のお知らせはメールやLINEで行う運用のため、名簿が流出するリスクを最小限に抑えられます。
   - ※部屋番号ごとの安否・負傷などの状況と、役員の認証用Googleアドレスは保存されます。スプレッドシートは住民に共有せず、非公開のまま運用してください。
3. **日英バイリンガル対応（🇯🇵 日本語 / 🌍 English）**
   - ヘッダーの `🌐 English / 日本語` ボタン（またはURL末尾の `?lang=en`）で、UI・モーダル・CSV出力まで即座に切り替わります。外国人居住者が多いマンションや海外のコンドミニアム・HOAでもそのまま利用可能です。
4. **2段階のセキュリティ（住民PIN ＋ 役員Passkey 1対1認証）**
   - **一般住民**: 「部屋番号 ＋ 各戸専用の4桁PINコード」だけでスマホから10秒で安否報告可能。他世帯のプライバシー情報（負傷・閉じ込め等の詳細メモ）はマスクされます。
   - **理事会・防災役員**: 個人のGoogleアカウント（指紋・顔認証Passkey対応）と担当部屋番号を **1対1で照合** し、誰がどの部屋を操作・リセットしたかを監査ログ（スプレッドシート＆GoogleドライブCSV）に自動記録します。
5. **Googleドライブへの年度別・自動整理（非公開で安全）**
   - 初回アクセス時に、管理組合のGoogleドライブ直下に **`マイドライブ > 安否確認システム > 2026年版`** のような年度フォルダを自動作成し、データベースとCSVバックアップを格納します。**Googleドライブのフォルダを住民に一般公開（共有）する必要はありません。**

## 🚀 導入ステップ（所要時間：約15分）

### Step 1: マンションの階数・部屋番号・マンション名を設定する

1. [`src/Code.gs`](./src/Code.gs) の先頭にある `DEFAULT_CONFIG`（23〜65行目付近）を、ご自身のマンションに合わせて書き換えます：
   - `BUILDING_NAME_JA` / `BUILDING_NAME_EN`: マンション名（例: `サンプルレジデンス` / `Sunrise Condominium`）
   - `TERM_TITLE_JA` / `TERM_TITLE_EN`: 年度・期数（例: `2026年度 (第12期)` / `FY2026 (Term 12)`）
   - `DRIVE_ROOT_FOLDER_NAME`: Googleドライブの親フォルダ名（既定: `安否確認システム`）
   - `DRIVE_YEAR_FOLDER_NAME`: 年度フォルダ名（既定: `2026年版`）
   - `FLOOR_CONFIG`: 各階の戸数設定（例: `{ 7: 8, 6: 11, 5: 15, ... }`）
2. [`src/index.html`](./src/index.html) 内の `APP_CONFIG`（1226行目付近）も同じマンション名・階数構成に合わせておくと、オフライン時やGitHub Pagesデモでも同じ部屋構成で表示されます。

### Step 2: 理事会・防災役員のGoogleアカウント（1対1認証）を設定する

1. **Googleグループ（任意・推奨）の活用**:
   - 管理組合用アカウントで [Google グループ](https://groups.google.com/) を作成（例: `your-condo-board@googlegroups.com`）し、今期の理事メンバーの個人Googleアドレスを登録しておくと、情報共有や引き継ぎが一元化できます。
2. **役員の部屋番号とGoogleアドレスの紐付け**:
   - [`src/Code.gs`](./src/Code.gs) の `ADMIN_ROOM_TO_EMAIL`（49行目付近）、または自動生成されるスプレッドシートの **`m_users` シート** に、役員の「部屋番号」と「個人Googleメールアドレス」を1対1で登録します（詳細は [docs/02_google_groups.md](./docs/02_google_groups.md) を参照）。

### Step 3: Google Apps Script (GAS) へデプロイする

1. 管理組合のGoogleアカウントで [Google Apps Script](https://script.google.com/) を開き、**「新しいプロジェクト」** を作成します。
2. **`コード.gs`** に [`src/Code.gs`](./src/Code.gs) の中身を貼り付けます。
3. エディタ左上の「ファイル `＋`」＞ **「HTML」** を選び、ファイル名を **`index`**（自動的に `index.html` になります）にして、[`src/index.html`](./src/index.html) の中身を貼り付けます。
4. 右上の **「デプロイ」＞「新しいデプロイ」** をクリックし、以下の設定でデプロイします：
   - **種類**: `ウェブアプリ`
   - **次のユーザーとして実行**: **`自分`**（※これにより、Googleドライブのフォルダを一般公開せずに安全に読み書きできます）
   - **アクセスできるユーザー**: **`全員`**（※住民が自分のスマホからすぐ開けるようにするため）
5. 発行された `https://script.google.com/macros/s/.../exec` のURLをQRコードにして、防災訓練の案内チラシや掲示板で住民へ配布します。

## 🔄 毎年の理事会引き継ぎ・URLローテーション運用

マンションの理事改選（年1回）に合わせて、以下の手順で新年度版へ移行することで、旧役員の権限残りやURL漏洩を防止できます：

1. GASプロジェクトを「コピーを作成」し、`DRIVE_YEAR_FOLDER_NAME` を翌年度（例: `2027年版`）に変更して新規デプロイします。
2. 自動生成された新しいスプレッドシートの `m_users` シートを新期の理事メンバーに更新します。
3. 旧年度のGASで「デプロイを管理」＞ **「アーカイブ」** を押すと、旧URLは即座に閉鎖され、Googleドライブの `安否確認システム > 2026年版` フォルダ内に当時の記録がそのままアーカイブ保存されます。
