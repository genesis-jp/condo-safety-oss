# 🔐 02. Googleグループ設定・パスキー管理者1対1認証ガイド
**Google Groups & Passkey 1-to-1 Admin Authentication Guide**

本システムでは、災害時や防災訓練時に全世帯の詳細情報（負傷・閉じ込め等の要支援メモ）を閲覧・代行入力できる **「管理者モード（理事会・防災役員用）」** を備えています。

共通パスワードの使い回しによる情報漏洩や「他人の部屋番号を騙った不正操作（なりすまし）」を防ぐため、**Googleアカウント（パスキー認証対応）と役員の部屋番号を1対1で照合するセキュリティ機構** を採用しています。

---

## 1. 認証アーキテクチャの概要（2段階セキュリティ）

| 利用者区分 | 認証方式 | 権限・プライバシー保護の範囲 |
|---|---|---|
| **一般住民**<br>(Residents) | **部屋番号 ＋ 4桁PINコード**<br>（例: `305`号室 ＋ PIN `0305`） | ・自室の安否・被害チェックリストの登録・更新<br>・全体マップの閲覧（**他世帯の要支援理由や個人メモは非表示にマスク**） |
| **理事・防災役員**<br>(Board Admins) | **個人Googleアカウント（パスキー）**<br>＋ **部屋番号1対1バインディング** | ・全世帯の詳細メモ閲覧、未回答世帯の**代行入力（上書き）**<br>・**A4記録シート印刷・PDF出力**、CSV出力<br>・訓練/本番モード切替、アナウンス編集、全件一括リセット |

### なぜ「1対1認証（Email-to-Unit Binding）」なのか？
たとえば「401号室の理事（`board401@example.com`）」が管理者ログインした場合、システムは自動的にその操作者を **「401号室の役員」として固定（ロック）** します。
401号室の理事が「501号室の理事」になりすましてログインすることはできず、すべての操作履歴（誰が・いつ・どの部屋を代行入力またはリセットしたか）が `t_audit_logs` シートおよびGoogleドライブ内の `操作監査ログ_2026年度.csv` に記録されます。

## 2. 理事会・防災委員会用 Googleグループの作成手順（推奨）

毎年の理事交代時にメーリングリストと権限管理を一元化するため、管理組合の共用Googleアカウントで **Googleグループ** を作成しておくことを推奨します。

1. 管理組合のGoogleアカウント（例: `your-condo-board@gmail.com`）で [Google グループ](https://groups.google.com/) にアクセスします。
2. 左上の **「グループを作成」** をクリックします。
3. グループ情報を入力します：
   - **グループ名**: `サンプルレジデンス 理事会・防災委員会`
   - **グループのメールアドレス**: `your-condo-board@googlegroups.com`
4. **プライバシー設定**（外部からのスパム防止と内部共有のため以下を推奨）：
   - **グループを検索できるユーザー**: `グループのメンバー`
   - **グループに参加できるユーザー**: `招待されたユーザーのみ`
   - **会話を閲覧できるユーザー**: `グループのメンバー`
   - **投稿できるユーザー**: `グループのメンバー`
5. **メンバーの追加**:
   - 今期の理事・防災委員の **普段使っている個人Googleメールアドレス**（`@gmail.com` または Google Workspace アドレス）をメンバーとして追加します。

## 3. 管理者（理事・役員）の1対1マスタ登録方法

管理者としてログインを許可する部屋番号とGoogleメールアドレスの紐付けは、以下の **2つの場所** のいずれか（または両方）で行えます。

### 方法A：スプレッドシートの `m_users` シートで管理する（コード変更不要・推奨）

運用途中で理事メンバーの追加やメールアドレス変更があった場合、プログラムを再デプロイせずにスプレッドシート上で即座に反映できます。

1. Googleドライブの `マイドライブ > 安否確認システム > 2026年版` フォルダ内にある **`マンション安否確認データベース_2026年度`** を開きます。
2. **`m_users`** シートを開きます。
3. 役員が住んでいる部屋番号（例: `401`）の行を探し、以下の2列を更新します：

| room_number | owner_name | primary_email | member_count | pin_code | is_admin | has_registered_email |
|---|---|---|---|---|---|---|
| `103` | （任意） | `board103@example.com` | `2` | `0103` | **`TRUE`** | `TRUE` |
| `202` | （任意） | `board202@example.com` | `3` | `0202` | **`TRUE`** | `TRUE` |
| `401` | （任意） | `board401@example.com` | `4` | `0401` | **`TRUE`** | `TRUE` |

- **`primary_email`**: 役員本人がスマートフォンやPCで使用しているGoogleメールアドレスを入力します。
- **`is_admin`**: **`TRUE`** に変更します（一般世帯は `FALSE`）。

### 方法B：ソースコード（`src/Code.gs` / `src/index.html`）の初期マスタに登録する

新年度にスプレッドシートを新規生成する際、最初から役員リストを反映させておきたい場合は、[`src/Code.gs`](../src/Code.gs) の `DEFAULT_CONFIG.ADMIN_ROOM_TO_EMAIL` と [`src/index.html`](../src/index.html) の `APP_CONFIG.adminRoomToEmail` に記述します。

```javascript
  // 理事・管理者（役員）の「部屋番号 : Googleメールアドレス」1対1紐付けマスタ
  ADMIN_ROOM_TO_EMAIL: {
    '103': 'board103@example.com',
    '202': 'board202@example.com',
    '301': 'board301@example.com',
    '401': 'board401@example.com'
  },
```

## 4. スマートフォン・PCでのパスキー（Passkey）ログイン手順

登録された理事メンバーは、パスワードを暗記することなく、スマートフォンの生体認証（Face ID / Touch ID / 指紋認証）を使って数秒で管理者モードに入室できます。

1. 理事メンバーが自身のスマートフォンまたはPCで安否確認システムのWebアプリURLを開きます。
2. ログイン画面上部のタブで **「🔐 管理者 (理事会・防災会)」** を選択します。
3. 以下のいずれかで1対1照合を行います：
   - **Googleセッション自動照合**: ブラウザで既に自分のGoogleアカウント（例: `board401@example.com`）にログインしている場合、バックエンドの [`verifyAdminRoleByGoogleSession()`](../src/Code.gs#L231) が自動的にメールアドレスを検出し、紐付けられた部屋番号（`401号室`）を特定します。
   - **登録メールアドレス＆部屋番号照合**: 画面上で自身の部屋番号（例: `401`）と登録済みGoogleメールアドレス（`board401@example.com`）を入力し、パスキー（生体認証）で承認します。
4. 照合に成功すると、ヘッダー右上に **`👑 管理者: 401号室`** と表示され、管理者専用機能（代行入力・A4記録シート出力・訓練モード切替）が解放されます。

> 🛡️ **なりすまし防止の動作確認**
> たとえば `401号室`（`board401@example.com`）の理事が、画面上で誤って `103号室` を選択してログインしようとしても、システムが「あなたのGoogleアカウントは401号室に紐付いています」と判定し、他室名義でのログインをブロック（または自室である401号室へ強制補正）します。

## 5. トラブルシューティング（管理者ログインできない場合）

| 症状・エラーメッセージ | 原因と対処法 |
|---|---|
| **「管理者権限が確認できませんでした」と表示される** | 1. スプレッドシート `m_users` シートの該当部屋番号の行で、`is_admin` 列が `TRUE` になっているか確認してください。<br>2. `primary_email` 列に入力したメールアドレスに前後の空白やスペルミスがないか確認してください。 |
| **スマホで別の家族のGoogleアカウントでログインしてしまう** | ブラウザ（Safari / Chrome）のシークレットウィンドウを開くか、画面上で「別のアカウントを使用」を選択し、`m_users` に登録した役員本人のGoogleアカウントでログインしてください。 |
