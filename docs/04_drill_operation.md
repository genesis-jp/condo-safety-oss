## 2. 訓練開始前の準備（管理者モード）

1. 防災担当理事がスマートフォンまたはPCでWebアプリを開き、**「🔐 管理者 (理事会・防災会)」** でログインします。
2. ダッシュボード下部の **「⚙️ システム管理・データ出力 (理事会専用)」** パネルを確認します：
   - **運用モード切替**: 訓練時は **`訓練モード (TRAINING)`**（オレンジ色のバッジ）にします。実際の災害発生時は **`災害本番モード (EMERGENCY)`**（赤色点滅バッジ）へ切り替えます。
   - **全体アナウンス設定**: 画面上部の黄色いバナーに表示するメッセージ（例: `【防災訓練】本日10:00〜11:00の間、安否確認訓練を実施中です。各世帯は速やかに報告してください。`）を入力して保存します。
   - **訓練データ全件リセット**: 訓練開始直前に **「🗑️ 全世帯の安否データを初期状態（未回答）にリセット」** を実行し、全戸を「🟡 未回答」状態からスタートさせます（※リセット前の記録も `t_safety_logs` には履歴として残ります）。

## 3. ダッシュボードの見方（色分けと枠線の意味）

管理者ダッシュボードの「建物フロア別 安否状況マップ」では、一目でマンション全体の状況が把握できるよう以下の色と枠線で表示されます。

### マスの背景色（安否ステータス）
- 🟢 **無事（緑）**: 世帯全員が無事
- 🔴 **要支援（赤・点滅）**: 負傷者あり、家具転倒・閉じ込め、介助が必要など最優先で駆けつけるべき世帯
- 🟣 **避難中（紫）**: 自宅を離れ、指定避難所や親族宅等へ避難中
- 🟡 **未回答（黄）**: まだ報告がない世帯（訪問・電話確認の対象）

### マスの枠線・バッジの意味
- **👑 オレンジ色太枠**: 理事・防災役員の部屋
- **✉ 青色太枠**: 連絡網メールアドレス登録済み世帯（太枠がない部屋はメール未登録のため、紙の安否札やインターホン確認を優先）
- **`[代]` 黒バッジ**: 住民本人ではなく、**理事・管理者が代行入力（上書き）した部屋**

## 4. 管理者による「代行入力（上書き）」の手順

スマートフォンを持たない高齢世帯や、停電・通信障害で入力できない世帯、あるいは未回答世帯を理事が訪問・電話で確認した場合は、**管理者がその場で代行入力**できます。

### 操作手順（2通りの開き方）
1. **方法①（マップから直接タップ）**:
   - フロアマップ上の対象部屋マス（例: `305`）をタップ（クリック）します。
2. **方法②（部屋番号を指定して開く）**:
   - ダッシュボード上部の **「✏️ 部屋番号を指定して代行入力」** ボタンを押し、部屋番号（例: `305`）を入力します。

### 代行入力モーダルでの登録手順
1. モーダル下部のオレンジ色の枠 **「✏️ 管理者による安否代行入力・上書き」** セクションを確認します。
2. **安否ステータス**（`🟢 無事 (全員安全)` / `🔴 要支援 (負傷・救助要請)` / `🟣 避難中 (自宅外へ避難)` / `🟡 未回答に戻す`）を選択します。
3. **世帯人数・無事人数**、および **停電・断水（漏水）の有無** を選択します。
4. **確認メモ・代行入力理由** を入力します。ワンタップ入力ボタンを使うと便利です：
   - **`[訪問確認済]`** ボタン → `【管理者代行】インターホン・訪問にて全員無事を確認` が自動挿入されます。
   - **`[電話確認済]`** ボタン → `【管理者代行】電話・LINEにて安否確認済` が自動挿入されます。
   - **`[安否札確認]`** ボタン → `【管理者代行】玄関ドアの安否確認マグネット（無事）を確認` が自動挿入されます。
5. **「💾 管理者権限で代行保存する」** を押すと即座に反映され、フロアマップの部屋マスに **`[代]`** マークが表示されます。
   - ※同時に「どの部屋番号の理事が、何時何分に、どの部屋を代行入力したか」が監査ログ（`t_audit_logs` およびGoogleドライブのCSV）に自動記録されます。

## 5. A4記録シートの印刷・PDF出力手順（1ページ完結帳票）

訓練終了後の理事会報告や1階エントランス掲示板への貼り出し、または実災害時に消防隊・自治体へ手渡すための **A4サイズ1枚完結の公式記録シート** を出力できます。

### 操作手順
1. 管理者ダッシュボード上部の青いボタン **「🖨️ A4記録シート出力 (縦・横プレビュー)」** をクリックします。
2. **A4出力プレビュー画面** が開きます。出力されるシートには以下の情報がA4・1ページ内に自動レイアウトされます：
   - **ヘッダー**: マンション名、運用期、訓練/災害モード区分、出力日時、出力管理者（部屋番号）、集計責任者署名欄
   - **全戸集計サマリー（6項目）**: 全戸数、回答済（回答率%）、無事、要支援、避難中、未回答
   - **フロア別 全戸安否カラーマップ**: 全階の部屋マス（色分け・枠線・`[代]`マーク・凡例付き）
   - **要支援・特記事項・ライフライン異常一覧テーブル**: 要支援世帯や停電・断水・特記メモがある部屋の一覧表（最大10件＋超過件数表示）
   - **総括メモ・引き継ぎ事項欄（直接編集可能）**: 画面上のテキストボックスをクリックすると、印刷前にその場で「第○回防災訓練 10:45最終集計。302号室はインターホンにて無事確認済み」などの申し送り事項を直接タイピングして追記できます。
3. **用紙向きの切り替え（縦 / 横）**:
   - プレビュー画面上部のツールバーで **`📄 A4縦 (Portrait)`** または **`🖼️ A4横 (Landscape)`** をワンクリックで切り替えられます（戸数が多いマンションや横長のフロア構成では「A4横」も見やすくおすすめです）。
4. **印刷またはPDF保存の実行**:
   - ツールバー右上の **「🖨️ このレイアウトで印刷 / PDF保存」** をクリックします。
   - ブラウザの印刷ダイアログが開くので、プリンターを選択して印刷するか、「送信先：PDFに保存」を選択してファイル保存します。

> 💡 **きれいにA4・1枚で印刷するコツ**
> ブラウザの印刷設定で **「背景のグラフィック（背景色と画像）」にチェック** を入れ、**「ヘッダーとフッター」のチェックを外す** と、部屋マスの色分けまで鮮明にA4用紙ぴったり1枚で出力されます。
