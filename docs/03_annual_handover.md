# 🔄 03. 年次引き継ぎマニュアル（年度更新・URLローテーション）
**Annual Board Handover Guide: URL Rotation, Data Archiving & Admin Transition**

マンション管理組合や自治会では、毎年（1期ごと）に理事・防災役員の改選が行われます。
本システムでは、**「過年度の訓練・災害記録を改ざん不能な状態でアーカイブ保存すること」** と **「退任した旧役員や転居者が古いURL・権限へアクセスし続けられないようにすること」** を両立するため、年1回の **年度更新（URLローテーション）** を標準フローとしています。

---

## 1. 年次引き継ぎの全体像（ビフォー・アフター）

年度更新を行うと、管理組合のGoogleドライブ（`マイドライブ > 安否確認システム`）内には、以下のように年度別のフォルダが自動的に積み上がっていきます。

```text
📁 マイドライブ (Google Drive)
 └── 📁 安否確認システム
      ├── 📁 2026年版  ← 【旧年度】デプロイをアーカイブ（URL閉鎖）し、記録は永久保存
      │    ├── 📊 マンション安否確認データベース_2026年度
      │    └── 📄 操作監査ログ_2026年度.csv
      │
      └── 📁 2027年版  ← 【新年度】新規デプロイにより自動生成！新URLを住民へ配布
           ├── 📊 マンション安否確認データベース_2027年度
           └── 📄 操作監査ログ_2027年度.csv
```

---

## 2. 引き継ぎ作業の5ステップ（所要時間：約15分）

通常総会終了後、新旧理事の引き継ぎ会（または新期の第1回理事会）にて以下の手順を実施します。

### Step 1: 新年度用のApps Scriptプロジェクトを作成する（コピー作成）

1. 管理組合の共用Googleアカウント（例: `your-condo-board@gmail.com`）で [Google Apps Script](https://script.google.com/) を開きます。
2. 前年度のプロジェクト（例: `マンション安否確認システム_2026年度版`）の右端にある「︙（その他のオプション）」をクリックし、**「コピーを作成」** を選択します（またはエディタ左上の「概要（ℹ️）」＞「コピーを作成」をクリックします）。
3. コピーされた新しいプロジェクトの名前を **`マンション安否確認システム_2027年度版`** に変更します。

---

### Step 2: 年度ラベルと新任役員リストを更新する

新しいプロジェクトの **`コード.gs`** と **`index.html`** の設定ブロックを新年度用に変更します。

#### ① `コード.gs` の `DEFAULT_CONFIG` を更新
```javascript
const DEFAULT_CONFIG = {
  BUILDING_NAME_JA: 'サンプルレジデンス',
  BUILDING_NAME_EN: 'Sunrise Condominium',

  // ★ 新年度の期・年度ラベルに変更
  TERM_TITLE_JA: '2027年度 (第13期)',
  TERM_TITLE_EN: 'FY2027 (Term 13)',

  // ★ 新年度のGoogleドライブ保存先フォルダ名・ファイル名に変更
  DRIVE_ROOT_FOLDER_NAME: '安否確認システム',
  DRIVE_YEAR_FOLDER_NAME: '2027年版',
  DRIVE_DB_FILE_NAME: 'マンション安否確認データベース_2027年度',
  DRIVE_AUDIT_FILE_NAME: '操作監査ログ_2027年度.csv',

  ADMIN_GOOGLE_GROUP: 'your-condo-board@googlegroups.com',

  FLOOR_CONFIG: { 7: 8, 6: 11, 5: 15, 4: 16, 3: 17, 2: 16, 1: 14 },

  // ★ 新任の理事・防災役員の「部屋番号 : Googleメールアドレス」に差し替え
  ADMIN_ROOM_TO_EMAIL: {
    '105': 'new-board105@example.com',
    '308': 'new-board308@example.com',
    '602': 'new-board602@example.com'
  },

  ALLOW_RESIDENT_PUBLIC_MAP: true
};
```

#### ② `index.html` の `APP_CONFIG` を更新
`index.html` 内の `APP_CONFIG`（1226行目付近）の `termTitleJa`, `termTitleEn`, `adminRoomToEmail` も同じ内容に更新し、`Ctrl + S`（Macは `Cmd + S`）で両ファイルを保存します。

---

### Step 3: 新年度版Webアプリを新規デプロイ（新URL発行）する

1. 新プロジェクトの右上 **「デプロイ」＞「新しいデプロイ」** をクリックします。
2. 種類で **「ウェブアプリ」** を選択し、以下の通り設定します：
   - **説明**: `2027年度（第13期）本番リリース`
   - **次のユーザーとして実行**: **`自分 (your-condo-board@gmail.com)`**
   - **アクセスできるユーザー**: **`全員 (Anyone)`**
3. **「デプロイ」** を押し、発行された新しいWebアプリURL（`https://script.google.com/macros/s/<NEW_DEPLOYMENT_ID>/exec`）を控え、ブラウザで1回開きます。
4. ブラウザで開いた瞬間に、Googleドライブ内に **`安否確認システム > 2027年版`** フォルダと **`マンション安否確認データベース_2027年度`** が自動作成されます。

> 💡 **世帯マスタ（PINコードやメール登録有無）を前年度から引き継ぎたい場合**
> 各戸で独自に変更したPINコード（`pin_code`）やメール登録状況（`has_registered_email`）をそのまま引き継ぎたい場合は、旧年度（2026年版）のスプレッドシートの `m_users` シートをコピーし、新年度（2027年版）の `m_users` シートへ値のみ貼り付けた上で、**F列（`is_admin`）とC列（`primary_email`）のみ新任役員に合わせて更新**してください。

---

### Step 4: 旧年度版のWebアプリURLを閉鎖（アーカイブ）する

新年度版の稼働を確認したら、前年度（例: 2026年度版）のURLから書き込みができないよう閉鎖します。

1. **旧年度（2026年度版）** のApps Scriptプロジェクトを開きます。
2. 右上の **「デプロイ」＞「デプロイを管理」** をクリックします。
3. アクティブなデプロイを選択し、右上の **「アーカイブ（箱のアイコン）」** をクリックします。
4. これで旧年度のURL（`.../exec`）は無効化され、万が一古いQRコードやブックマークからアクセスされてもシステムは動作しなくなります。
   - ※Googleドライブ上の `安否確認システム > 2026年版` フォルダ内のスプレッドシートや監査ログCSVは消えずにそのまま保全されます。

---

### Step 5: Googleグループのメンバー入れ替えと新QRコード配布

1. [Google グループ](https://groups.google.com/)（`your-condo-board@googlegroups.com`）を開き、退任した旧役員のメールアドレスを削除し、新任役員の個人Googleメールアドレスを追加します。
2. 新任役員全員に、自身のスマートフォンから新しいWebアプリURLへアクセスし、**「🔐 管理者 (理事会・防災会)」** タブでログインできるかテストしてもらいます。
3. 新しいWebアプリURLのQRコードを作成し、防災訓練案内やマンション掲示板・ポータルサイトで住民へ周知します。
